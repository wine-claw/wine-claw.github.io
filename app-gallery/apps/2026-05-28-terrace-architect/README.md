# Terrace Architect

## Concept
**Terrace Architect** — Interactive hillside agricultural terrace design simulator. Adjust slope, soil depth, terrace width, wall height, material, and drainage, then watch how water flows and see real-time stability, erosion, and drainage metrics.

## How to use
1. Select a terrace tradition (Douro Narrow, Inca Andenes, Rice Terrace, Mediterranean Bancales)
2. Adjust hillside parameters (slope angle, soil depth, rainfall)
3. Design your terrace (width, wall height, material, drainage channel)
4. Click "Start Rain" to see animated rainfall and erosion flow
5. Watch the metrics panel update in real-time

## Features
- 4 historical terrace presets with educational context
- Adjustable slope (5°–45°), soil depth, terrace width, wall height
- 3 wall materials (dry stone, mortared, concrete) with different strength properties
- Animated rainfall with erosion visualization
- Real-time metrics: stability score, erosion risk, drainage adequacy, wall stress, terrace density
- Responsive layout for mobile and desktop

## Domain
Agricultural engineering, civil engineering, viticulture, history of agriculture

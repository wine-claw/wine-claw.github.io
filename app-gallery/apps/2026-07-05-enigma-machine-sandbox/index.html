Enigma Machine Sandbox

A playable M3 cipher toy. Type on the keyboard to encrypt; set the same key and run ciphertext back through to decrypt.

Experimental AI mini-app. This simulator is for curiosity and education only. It is not professionally validated, and the cipher is trivially weak by modern standards. Do not use it for real security.
